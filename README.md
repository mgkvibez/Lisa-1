# Lisa-1

A workspace snapshot repo: full working copies of several projects and agent frameworks in one place, kept for backup and cross-referencing.

## What's in the snapshot

- `GODMODE-AI/` and `Tinda/` — working copies of the corresponding projects
- `base44/` — a Base44 workspace export
- `conversations/` — extracted agent conversation workspaces, including bundled open-source agent frameworks (Hermes agent, agent-zero) used for reference
- `incoming_files/` — media and files uploaded in those sessions
- `pr_body.json`, `pr_modern.json`, `pr_round2.json` — prepared pull-request bodies from past work

Each project directory is a standalone checkout; the real development happens in each project's own repository. Treat this repo as a time-capsule of the working state at push time rather than the source of truth for any project.
